# 教材映射与课程范围

[手册目录](../README.md#章节目录) · [课程地图](course-map.md) · [实验说明](evidence.md)

本页说明课程如何取材、哪些内容做了教学简化，以及后续材料需要补强什么。章节目录见 [首页](../README.md#章节目录)，学习目标与阶段验收见 [课程地图](course-map.md)。

本手册的章号独立于 Hello-Agents。01–11 章分为基础机制、上下文与任务组织、检索与质量、框架与协议四部分；第 12 章是医疗险综合实战。天气与课程问答用于讲清单个机制，医疗险比较承担综合业务任务。

## 范围与验收边界

Hello-Agents 第五章低代码平台实践跳过；第六章只选 LangGraph，不加入 AutoGen、AgentScope 或 CAMEL。多 Agent、A2A、ANP、模型训练和长期记忆不在课程范围。框架与协议先通过小例学习，再用医疗险比较检查相同业务规则在不同入口中的表现。

规划与 Reflection 章节保留独立练习。医疗险实现采用程序生成的任务计划、模型选择取证工具和程序证据校验；没有将模型规划器或自动评审修订循环全部接入业务。课程问答仍作为 [检索与引用专项练习](practice/research-agent.md)，不承担另一条产品建设主线。

课程成果以可以解释的消息流、任务组织、检索判断和业务比较为准。逐题检查证据和条件，不以成功退出替代答案核验。医疗险比较不执行投保、付款或承保决定；报价和资料缺口的处理规则见 [业务任务书](insurance/requirements.md)。

## 后续建设与完成条件

后续工作优先完善第 12 章的资料、案例与验收。现有教学目录、官方摘录和工具轨迹提供了学习起点；下面的工作用于检验这些规则能否处理更多条件，不新增第二个综合项目。

| 优先项 | 要补强的材料 | 完成条件 |
| --- | --- | --- |
| 条款与适用条件 | 按 [资料规范](insurance/data-guide.md) 核对现有摘录，补充有明确来源的必要条件 | 每条事实能够定位产品、资料版本和原文；缺失内容仍标未知，不借其他版本补齐 |
| 独立验收题 | 增加与正文示例不同的关注点、版本错误、无报价和预算不足场景 | 先标注必需证据与预期状态，再逐题检查；报告流程完成与业务问题未解决的差别 |
| 同题对照与讲解 | 对照本地、LangGraph 和 MCP 入口的输入、事实、缺口及停止条件 | 指出共享规则与调用边界，保留失败结果；不根据工具次数多少直接评价质量 |

每次补充材料都应对应一个具体问题。需要新增机制时，先用现有案例说明缺口，再评估它是否服务于需求理解、取证或比较；不把增加步骤本身当成课程进步。
