## 推进顺序

1. **模型与工具基础**：单次调用 → 工具执行 → 结果回传 → 有限循环 → 带来源回答。目前已具备可运行原型。
2. **状态与上下文基础**：先理解现有代码的 `messages`、工具结果和程序计数；选读第九章 §9.1、§9.2.1，做一个小型预算上下文实验。这里只补当前项目需要的概念，不代表直接学完整个第九章。
3. **规划与反思**：回到第四章 §4.3、§4.4，分别实现最小例子，再与当前 ReAct 流程比较。
4. **检索与评估**：结合第八章与第十二章，改进检索与来源质量，沿用固定问题观察变化。
5. **LangGraph**：学习第六章 §6.5.1–6.5.3，先运行教材三步问答助手，再迁移已有循环；结合第七章阅读选定调用链。
6. **协议与项目完善**：第十章 MCP 小实验，以及第十四章相关研究项目方法。

## 本轮范围

第五章低代码平台实践跳过。第六章只选择 LangGraph，不安排 AutoGen、AgentScope、CAMEL。多智能体、A2A、ANP、训练与长期记忆不进入本轮验收。
