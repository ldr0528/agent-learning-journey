## 下一步具体做什么

学习者已完成完整历史与摘要模式的真实对照：两次均查询北京、上海后有效 Finish，共 3 次模型请求、2 次工具执行。摘要在第三次请求前由 Python 生成，结果支持此次比较，但不能据此声称降低成本或提高正确率。

现在回到第四章 §4.3.1–4.3.2，沿用三天销量题，一次模型请求生成步骤列表。先检查计划，再学习 §4.3.3 的逐步执行与结果回传。入口与解释见 [第 6 章](learning/planning.md)；当前只准备规划器，尚未完成 Plan-and-Solve 全流程或 Reflection。
