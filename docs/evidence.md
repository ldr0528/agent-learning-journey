## 新课程内容如何验证

| 验证方式 | 验证什么 | 不能据此宣称什么 |
| --- | --- | --- |
| 固定回复的离线测试 | 请求内容、循环、预算、状态与错误出口 | 真实模型会作出同样选择 |

| MCP 本地 stdio 实际运行 | 会话、工具发现与跨进程调用 | 获得实时互联网数据或额外模型能力 |
| 人工核对引用与答案 | 当前结论能否被给定来源支持 | 自动完成所有事实核查 |

各章说明演示模式与结果，固定数据明确标注。自动检查见 [GitHub Actions](https://github.com/ldr0528/agent-learning-journey/actions)。基础环境缺少可选库时会明确跳过相关测试；专门集成环境安装库后实际验证框架与协议。

## 本版验证记录

2026-11-19，本地 Windows / Python 3.12 验证结果：

- 基础环境：58 项测试中 50 项通过，8 项因未安装可选库而跳过。
- 安装全部可选依赖后：58 项测试全部通过，无跳过；`pip check` 未发现依赖冲突。
- 12 个无需模型 API 的示例入口全部运行通过，包含实际 LangGraph 和 MCP 调用。
- 文档检查覆盖 11 章、28 段 Python、相对链接、标题锚点、SVG、JSON 及关键函数与源码的一致性。
- 固定开发题的检索结果：Recall@3 为 0.9583，MRR@3 为 1.0，无答案题空结果比例为 0.5。失败案例保留在 [评估章](learning/evaluation.md)，这些指标不等于回答正确率。

云端检查还覆盖 Ubuntu 与 Windows、Python 3.10 与 3.12；具体提交是否通过，以对应 [Actions 运行](https://github.com/ldr0528/agent-learning-journey/actions) 为准。本版没有替学习者调用付费模型验证新增章节的生成质量。
