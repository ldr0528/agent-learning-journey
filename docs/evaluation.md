# 评估与验收

[返回首页](../README.md) · [检索与引用](learning/retrieval-and-citations.md) · [复现指南](getting-started.md)

固定问题用于复现行为，离线测试用于验证控制逻辑。两者分别执行，不把模拟模型回复当作真实模型质量证据。

## 固定问题

| 编号 | 问题 | 上限 | 验收标准 |
| --- | --- | --- | --- |
| R01 | Agent Loop 为什么要有最大步数？ | 5 | 引用 N03，解释执行预算；区分上限与任务完成 |
| R02 | Action 和 Observation 分别由谁产生？ | 5 | 引用 N02，区分模型请求与程序组织的结果 |
| R03 | 只把工具结果打印到终端，模型下一轮就能看到吗？ | 5 | 引用 N02，说明打印不等于发送到下一次请求 |
| R04 | LangGraph 的 checkpoint 有什么作用？ | 5 | 当前资料不足，明确说明，不编造解释或引用 |
| R05 | Agent Loop 为什么要有最大步数？ | 1 | 未取得有效 Finish 时返回 `step_limit`，不额外请求 |
| R06 | Agent Loop 的资料能说明 LangGraph checkpoint 如何恢复状态吗？ | 5 | 即使命中 N01，也不能据此编造 checkpoint 方法 |

运行示例：

```bash
python -m agent_learning --question "Action 和 Observation 分别由谁产生？"
python -m agent_learning --question "Agent Loop 为什么要有最大步数？" --max-steps 1
```

## 判定维度

逐题检查：资料是否支持回答、引用是否来自本次结果、是否正确停止，以及模型请求与实际工具执行各多少次。没有资料时诚实说明可以通过边界测试，但不是成功解答了原问题。

R05 返回退出码 1 是符合预期的结果；不能仅用所有命令是否返回 0 判断测试通过。

## 用实验检查理解

运行前预测要请求模型几次、执行工具几次；运行后逐轮指出“谁产生了这段内容，下一次模型输入增加了什么”。然后说明资料是否支持结论，以及程序为何接受或拒绝结束。

能得到答案、能读懂轨迹、能修改一个条件并解释变化，是不同层次的进展。仓库记录实验与代码证据，不以测试数量代替学习掌握程度。

## 已有验证范围

手册已经保留学习者提供的天气、本地摘要问答、资料不足与上下文对照等真实千问 `qwen-plus` 输出。不同任务的记录来自不同实验轮次，不是一个可比较的批量基准，也不宣称普遍成功率。六道固定题继续作为复测清单，不能把列表本身当成当前版本全部实测通过的证据。

分层后的版本通过离线测试与实际入口复测，具体结果以当前提交的测试运行和 Actions 状态为准。源码仍会受到模型输出波动影响。

## 离线控制逻辑

```bash
python -m unittest discover -s tests -v
```

测试使用固定的模拟模型回复，覆盖工具结果保留到下一轮、预算耗尽、无效工具、资料不足、格式修正、引用范围、查询去重、任务间数据隔离及服务配置。不读取本地真实密钥，不请求外部 API。

这些任务是依据 [Hello-Agents 第四章](https://github.com/datawhalechina/hello-agents/blob/main/docs/chapter4/第四章%20智能体经典范式构建.md) 编排的工程练习，不是教材原题。

## 研究报告验收清单

- **检索**：原始问题、参数、实际返回编号与入选证据可追踪。
- **数据**：来源是教学摘要还是原文，资料日期和适用范围是否清楚。
- **回答**：每条关键结论有直接支持，未把主题相关当成可回答。
- **引用**：编号来自实际发送给模型的证据，最终链接从资料记录读取。
- **缺失**：没有证据或证据不足时说明缺什么，不声称教材没有相关内容。
- **预算**：请求次数与实际调用一致，失败没有自动被掩盖。
- **可复现**：保存语料指纹、分块参数、模型配置标识、代码版本与测试题；不保存密钥。

已有离线报告的 `evidence_only` 表示仅提供摘录。真实生成的 `answered` 只表示通过格式和引用范围检查，还需人工核对上面的事实要求。

提供真实回答记录后，可以额外计算引用合法率与逐条结论引用覆盖率：

```bash
python -m examples.evaluate --predictions outputs/predictions.json --output outputs/full-evaluation.json
```

记录格式见 [引用评估说明](learning/evaluation.md#96-加入真实回答记录)。程序不会为缺失的真实样本伪造答案，也不会把模拟模型的固定回复当成质量成绩。
