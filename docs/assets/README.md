# 手册图示规范

本目录保存手册的原创 SVG。图示采用白底、细线、少量配色，直接表达程序中的参与者、信息流和控制分支。图片内只保留关键标注，详细解释放在正文。

## 视觉约定

| 元素 | 约定 |
| --- | --- |
| 画布 | 宽 1280；白色背景；左右至少 48 的留白 |
| 字体 | Segoe UI、Microsoft YaHei；代码标识使用 Consolas |
| 字号 | 图标题 30；主要节点 22–27；说明 18–20；辅助代码标签可用 16–17 |
| 普通文字 | 深灰 `#20293A`；辅助说明 `#6B7585` |
| 模型与请求 | 蓝色 `#3867D6`；必要时使用极浅蓝填充 |
| 工具、程序处理与回传 | 绿色 `#27816C`；必要时使用极浅绿填充 |
| 预算停止 | 橙色 `#B36535`，用于区别正常完成 |
| 连线 | 约 1.5–1.7；箭头保持小而清楚；避免穿过节点或文字 |
| 外观 | 小圆角、无阴影，不用大面积深色标题栏或装饰性卡片 |

## 按内容选结构

- 时间顺序与职责分工使用时序图，如工具结果回传。
- 反复执行与停止条件使用带回路、分支的流程图。
- 资料如何进入回答使用数据流图，明确查询、返回与来源读取的方向。
- 章节路线使用层次与顺序关系，区分已有正文和后续计划。

每张 SVG 保留 `title`、`desc` 与可编辑文本。更新后渲染检查文字、箭头与节点是否重叠，并同步正文图注；缩小到文档宽度时仍应能读清主要标签。

视觉参考与许可范围见 [NOTICE.md](../../NOTICE.md)。
